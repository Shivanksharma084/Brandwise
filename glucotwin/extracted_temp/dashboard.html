Dataset Overview

Target variables, splits, and dataset characteristics

Classification

smart_wearable

Target: health_risk (0 / 1)

Split: stratified rows (70 / 15 / 15)

Features: BMI, BP, heart rate, steps, stress

Regression

glucotwin

Target: glucose t+30 / 60 / 90 / 120

Split: by participant (70 / 15 / 15)

Features: Dexcom CGM, meal carbs, insulin

Mixed

cgm_t1dm_t2dm

Target: cgm t+30, hypo_60

Split: by patient (70 / 15 / 15)

Features: T1DM + T2DM combined data

Mixed

ohhim

Target: glucose t+30 / 60, hypo_60

Split: temporal per patient (70 / 15 / 15)

Features: OhioT1DM style, wearable signals
